이 강의가 다루는 것

회귀분석에 대한 이해를 돕기 위해 통계학과 학부 수준에서 다루는 기본적인 내용만을 담았습니다. 회귀분석의 이론적 배경과 수학적 증명은 최소화하고, 통계학 전공자가 아니더라도 회귀분석을 이해하고 활용할 수 있도록 구성했습니다.
