**기준 원본**: `quarto/agent/2026-08-26/01-introduction.qmd` 의 `::: notes` **IDX 0(도입부)·IDX 1(회귀분석이란)**. 사용자가 2026-08-30 직접 작성했다. 앞으로 노트 대본은 **이 두 블록의 톤과 용어를 기준**으로 쓴다. 이 두 블록은 손대지 않는다([[respect-user-edits]]).

**문체 특징(실제 문장에서 추출)**

| 요소 | 사용자 문체 |
|:--|:--|
| 청중 관계 | 연구 경험을 인정하고 질문을 던짐 — "이미 회귀분석을 수행한 경험이 모두 있으실 것", "~사용하고 계신가요?" |
| 도입 | 개념 설명 전에 **질문 → 상식적 답 → 개념** 순서 |
| 예시 | 구체적 수치 — "대한민국 사람의 키 170cm", "아버지의 키가 180cm" |
| 문장 길이 | **짧게 끊지 않고 길게 이어 씀.** 연결어미로 문장을 잇는다 |
| 요약 | "**즉,** ~입니다"로 문단을 닫음 |
| 메타 코멘트 | 강의 운영·자료 선정 경위를 솔직히 밝힘 — "2-3시간 동안 모두 다루기는 어렵기 때문에", "인터넷 검색을 통해 골라서 가져왔습니다" |
| 인칭 | "우리는", "여러분들" |
| 문단 | 빈 줄로 2~4개 문단 구분 |
| 용어 | "측정 및 관찰에서 발생할 수 있는 오차", "무게중심", "특정 조건이 주어졌을 때 결과의 평균" |

**중요 — 내 이전 정비 기준과 충돌하는 부분**: 사용자는 `매우`, `굉장히`, `널리`, `즉,` 을 자유롭게 쓴다. 2026-08-30 1차 윤문에서 내가 이것들을 "과장 수식어·AI 상투구"로 보고 걷어냈는데 **사용자 본인 문체에서는 정상 어휘**다. 앞으로 이 계열을 기계적으로 제거하지 말 것. 관련: [[slide-register-rule]], [[notes-revision-2026-08-30]]

**적용 현황(2026-08-30)**: **01장만** 이 문체로 재작성 완료(IDX 2~21, 20개 블록). **02~08장은 아직 1차 윤문 상태**라 문체가 다르다. 확장 여부는 사용자 지시 대기.
