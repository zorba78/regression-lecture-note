**자료**: `data/derived-data/galton-stata11.tab` (사용자 업로드, 2026-08-24). 탭 구분, 열은 `family, father, mother, gender, height, kids, male, female`. **197 가족의 자녀 898명**(아들 465, 딸 433). 키 단위는 인치.

이전에 쓰던 모의자료(피어슨·리 1903의 발표값 절편 33.89 / 기울기 0.51 / n=1078을 재현하도록 생성)는 **더 이상 쓰지 않는다.** 생성 스크립트 `code/agent/2026-08-13/make-intro-figures.R`는 남아 있으나 그림은 대체됨.

**현재 슬라이드에 실린 값** (모두 이 파일에서 재계산, 유효숫자 3자리 규칙 적용 — [[no-r-code-theory-first]])

| 항목 | 값 |
|:--|:--|
| 아버지 → 아들 (n=465) | $\hat y = 38.3 + 0.448x$ |
| 표준오차 / t | 3.39, 0.0489 / 11.3, 9.15 |
| ANOVA | 회귀 SS 492 (df 1), 잔차 SS 2721 (df 463), MSE 5.88, F 83.7 |
| $R^2$ / r / $\hat\sigma$ | 0.153 / 0.391 / 2.42 |
| 아들 평균 / $E(Y\mid X=72)$ | 69.2 / 70.5 (실제 72±0.75 구간 36명의 평균은 70.9) |
| 중간부모 → 자녀 (n=898) | $\hat y = 18.8 + 0.729x$, r 0.511, $\hat\sigma$ 2.23 |
| 자녀 평균 / $E(Y\mid X=72)$ | 69.2 / 71.3 (실제 72±0.75 구간 62명의 평균은 70.8) |

**중간부모 값이 중요한 이유**: "골턴은 2/3라 했는데 왜 0.448이냐"는 질문에 같은 파일로 답할 수 있다. 중간부모를 설명변수로 쓰면 0.729가 나와 골턴의 0.667과 같은 계열이고, 아버지 한 사람만 쓰면 0.448이다. 설명변수 선택이 기울기를 바꾼다는 것이 답이며, 이 내용은 `Galton 자료에 대한 단순선형모형 적합` 슬라이드 노트에 들어 있다. 중간부모 계산은 `(father + 1.08*mother)/2`, 딸의 키는 1.08배 (골턴의 환산).

**그림**: `output/agent/2026-08-24/fig-i01..i04`, 생성 스크립트 `code/agent/2026-08-24/make-galton-real-figures.R`.
- **2026-08-30: fig-i01·i02·i03을 중간부모 → 자녀(n=898)로 교체**했다. 사용자가 "Galton과 회귀의 기원" 슬라이드 노트를 중간부모 이야기로 새로 쓰면서 "빨간 선이 1:1, 파란 선이 적합선"이라고 명시했고, 이어서 뒤 두 장(7/25 주변·조건부분포, 8/25 국소평균)까지 통일을 요청했기 때문이다. 새 그림은 모두 `output/agent/2026-08-30/`, 스크립트는 `code/agent/2026-08-30/make-galton-midparent-scatter.R`(i01)와 `make-galton-midparent-conditional-figures.R`(i02·i03). fig-i01은 빨강 실선 $y=x$, 파랑 실선 적합선, 두 평균에 점선 십자.
- **2026-08-30 (2차 요청): fig-i04(9/25 회귀의 정의)와 "Galton 자료: 모형 적합"(11/25)까지 중간부모 → 자녀로 교체**해, 01장 안에서 아버지 → 아들 값은 더 이상 슬라이드에 없다. 새 표는 절편 18.8(SE 2.84, t 6.61), 기울기 0.729(SE 0.0410, t 17.8), ANOVA 회귀 SS 1575(df 1) · 잔차 SS 4469(df 896), MSE 4.99, F 316, $R^2$ 0.261. fig-i04의 조건부 정규밀도는 $x$ = 65, 69, 73에 그렸고 각 조건부 평균은 66.2 / 69.1 / 72.0이다. 아버지 → 아들 값(38.3 + 0.448x)은 노트에서 "설명변수를 바꾸면 기울기가 이렇게 달라진다"는 대비로만 언급된다.
- fig-i01에 $y=x$ 파선을 추가해 적합선이 더 완만하다는 것(=회귀)이 눈에 보이게 했다(2026-08-24판, 아버지 → 아들).
- **fig-i03은 국소평균 구간을 색 띠로 표시**(사용자 요청). 파란 두 톤을 번갈아 칠해 1인치 구간을 하나씩 구분하고, 관측이 10명 미만이라 국소평균을 찍지 않은 구간은 회색으로 둔다. 교대 색을 쓸 때 한쪽을 흰색으로 두면 절반만 표시된 것처럼 보이므로 **양쪽 모두 보이는 색**을 쓸 것.

**주의**: 이 파일이 어느 판본인지(핸리의 재구성본인지 등) 확인하지 못했다. 슬라이드에는 파일에서 직접 셀 수 있는 사실(197 가족, 898명, 아들 465)만 적었다. 출처를 정확히 인용해야 하면 사용자에게 판본을 확인할 것.
