`references/.../7장/ice.csv.csv`의 `year`(0/1/2)는 **관측 연차(몇 년째 기록)** 구분이다. 기간 1–10 = 0, 11–23 = 1, 24–30 = 2이며 각 연차 안에 겨울~여름 온도(24~72°F)가 모두 포함되어 있어 계절 지표가 아니다. 슬라이드·해석에서 "시즌/계절"로 쓰면 사실 오류(검증 에이전트가 원자료 대조로 확인, 2026-08-12). 제9장 가변수 해석은 "시간에 따른 소비 수준 상승"으로 서술할 것.
