슬라이드에 **R 코드·R 함수명·R 문법을 넣지 않는다**. 계산 과정을 보여야 할 때는 R 호출 대신 **수식으로 전개**한다. 강의의 무게중심은 이론이다.

**Why:** 청강자(원자력안전기술원 연구원)가 R을 모를 가능성이 높다고 사용자가 2026-08-24에 명시. R 코드는 이해를 돕기는커녕 낯선 기호를 하나 더 얹는다. `lm(IC ~ price + income + temp)` 는 R을 아는 사람에게만 정보이고, 모르는 사람에게는 `~`, `$`, `%*%` 가 전부 새 기호다.

**How to apply:**
- 금지: 코드블록(` ```r `), `lm()`·`summary()`·`step()`·`factor()` 같은 함수명, `y ~ x` 물결표 문법, `weights` 같은 인자명, `Std. Error`·`Pr(>|t|)` 같은 R 출력 열 이름, 패키지 이름(nlme 등), R 내장자료 이름(longley 등).
- 대체 방법 — R 코드가 있던 자리에 다음 중 하나를 넣는다:
  - **손계산 전개**: 자료 → 통계량 → 추정값 → 표준오차 → 검정통계량의 사슬을 수식으로 (예: $S_{xy}/S_{xx}\to\hat\beta_1\to\mathrm{SE}\to t$)
  - **대수적 증명**: `all.equal(H, t(H))` 대신 $\mathbf H^\top=\mathbf H$ 의 증명
  - **차원 추적**: $\underbrace{\mathbf X^\top}_{4\times 30}\underbrace{\mathbf X}_{30\times 4}$ 처럼 행렬 크기를 밑에 달기
  - **모형식 명시**: 적합 함수 호출 대신 $y_i=\beta_0+\beta_1x_i+\beta_2d_{i1}+\varepsilon_i$
  - **행렬 구조 제시**: 자기상관은 AR(1) $\boldsymbol\Sigma$ 행렬을 직접 그림
- 결과 수치표(계수·표준오차·p-value·$R^2$·AIC)는 **유지한다**. R을 몰라도 읽히고 이론의 착지점이 되기 때문. 다만 열 이름과 항 이름은 수학 기호로 적는다(`factor(year)1` → $\hat\beta_2$ ($d_1$: year = 1)).
- 숫자를 새로 넣을 때는 반드시 원자료로 검산한다. 자료는 `references/cnu-regression-lecture-note/강의노트/R 예제/7장/ice.csv.csv` (n=30). 관련: [[ice-data-year-variable]]

**수치 표기(2026-08-24 지시)**: 모든 수치는 **유효숫자 3자리**. 각주로 "반올림값임"을 달지 않는다.
- 따라서 화면에 대입 계산을 적을 때는 **3자리에서 딱 떨어지는 형태로만** 적는다. 떨어지지 않으면 대입을 빼고 식과 결과만 남긴다(예: $t=\hat\beta_1/\mathrm{SE}=6.50$).
- 식을 바꾸면 떨어지는 경우가 많다. 예: $\hat\sigma/\sqrt{S_{xx}}$ 는 0.0423/88.4 = 0.000479로 어긋나지만, $\sqrt{\hat\sigma^2/S_{xx}}=\sqrt{0.00179/7820.7}=0.000478$ 은 맞아떨어진다.
- **예외(반올림하면 값이 붕괴하므로 유지)**: AIC 계열 11종(−107.21/−107.48/−194.34/… 및 상수 85.136, 87.136) — 3자리면 −107로 같아져 모형 비교가 불가능. t·z 임계값 4종(2.048, 3.182, 2.228, 1.960) — 표에서 읽는 값. $S_{xx}=7820.7$ 과 physics 자료 4종(549.5, 602.4, 144.8, 136.6) — 소수 1자리라 이미 짧음.
- DOI 번호(10.1021, 10.3390)는 수치가 아니므로 절대 건드리지 않는다.
