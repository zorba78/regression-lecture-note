# 강의자료 품질 점검

대상 파일을 읽고 아래 체크리스트를 **전부** 점검한 뒤, 결과를 표로 보고한다.
지적만 하고 수정은 하지 않는다. 수정은 사용자가 요청할 때 수행한다.

## 체크리스트

### 1. 눈높이 (특강의 핵심 요구)
- [ ] 새로 등장하는 모든 핵심 개념에 비유/직관 설명이 수식보다 먼저 나오는가?
- [ ] 한 슬라이드(절)에 아이디어가 하나인가? 글머리표가 5개를 넘지 않는가?
- [ ] 전문용어가 정의 없이 처음 사용된 곳은 없는가?

### 2. 수식
- [ ] 모든 수식의 기호가 설명되어 있는가?
- [ ] 유도 단계를 직접 따라가며 검산했을 때 오류가 없는가? (검산 과정을 보고에 포함)
- [ ] 표기가 문서 전체에서 일관적인가? (예: $\beta$ vs $b$, 벡터/스칼라 구분)

### 3. 언어 규칙 (CLAUDE.md 행동 규칙 5)
- [ ] 본문은 한국어인가?
- [ ] 그림·표의 제목, 캡션, footnote는 영어인가?
- [ ] 코드 주석은 영어인가? 스크립트 헤더(날짜·개요·파일명)가 있는가?

### 4. 근거·객관성 (CLAUDE.md 윤리적 제약)
- [ ] 이론적 주장마다 출처(references의 장 또는 문헌)가 있는가?
- [ ] 추측·의견이 사실처럼 서술된 곳은 없는가?
- [ ] 수치는 계산 과정과 함께 제시되는가?

### 5. 실행 재현
- [ ] qmd는 `quarto render`가 통과하는가?
- [ ] R 스크립트는 `Rscript` 실행이 통과하고 그림이 지정 경로에 생성되는가?
- [ ] 난수 사용 코드에 `set.seed()`가 있는가?
