# 개념 이중 트랙 설명 (Easy Explain)

박사급 청중에게 강의하지만 설명 자체는 초등학생이 이해할 수 있어야 한다.
모든 개념 설명은 아래 5단계 구조를 따른다.

## 출력 구조

1. **비유 (한 문단)**: 일상 경험에 기반한 비유로 시작. 숫자와 기호를 쓰지 않는다.
   - 비유는 개념의 핵심 메커니즘과 구조적으로 대응해야 한다. 겉모습만 닮은 비유 금지.
   - 청중 특성(원자력 안전, 계측·검교정, 신뢰성 평가)에 맞는 예시를 우선 고려한다.
2. **그림 (권장)**: 비유를 시각화할 수 있으면 산점도·개념도 등 간단한 그림을 제안하거나 R로 생성한다.
3. **정식 정의**: 수식을 제시하고, 수식의 **모든 기호를 하나씩** 한국어로 설명한다.
   - 수식 없는 정의 금지. 설명 없는 수식도 금지 (CLAUDE.md 행동 규칙 4).
4. **비유와 수식의 연결**: 비유의 각 요소가 수식의 어느 부분에 해당하는지 명시한다.
5. **흔한 오해**: 이 개념에서 비전문가가 자주 틀리는 지점 1~2개와 비유의 한계를 밝힌다.

## 근거 규칙

- 이론적 주장은 `references/` 강의노트 또는 검증 가능한 교과서·논문에 근거하고 출처를 명시한다.
- 확인할 수 없는 내용은 "이것은 확인할 수 없습니다"라고 명시한다 (CLAUDE.md 윤리적 제약).
- 수치 예를 들 때는 계산 과정을 함께 제시한다.
